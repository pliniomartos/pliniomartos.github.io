Overview

Sustain Energy is a certification platform built as the Graded Unit for my HND in Software Development at Edinburgh College. The application supports sustainability certification workflows with a responsive, mobile-first interface.

Key features

  • Dynamic content driven by a MySQL database with a custom schema design
  • Automated certificate generation with print-ready formatting
  • LinkedIn integration for sharing achievements directly to a user’s profile
  • Full user authentication, admin dashboard and responsive UI

Code available on request. This is coursework, so the repository is not public. Email me if you would like to review the source.

Role

Sole developer — design, database schema, back end, front end and authentication.
