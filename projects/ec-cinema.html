Overview

EC Cinema is a full-stack booking system developed as the final project for my HNC in Software Development at Edinburgh College. It covers the full booking journey: browsing films, paying securely, receiving QR tickets and managing content from an admin dashboard.

Key features

  • Stripe API integration for secure payments, with automated QR ticket generation
  • OMDb API integration to auto-populate film data (posters, ratings, plots)
  • User authentication, booking history, review system with likes, and admin dashboard
  • Security hardening: SQL injection prevention, XSS protection, password hashing

Source code is public. Repository: github.com/pliniomartos/cinema-hnc

Sole developer — payments, APIs, authentication, security and admin tools.
